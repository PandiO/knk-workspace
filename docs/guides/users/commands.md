| Permission | Description |
|---|---|
| `k&k.arena` | Gives permission for creating and editing arena's |
| `k&k.coins` | Allows to change the coin amount of players |
| `k&k.gems` | Allows to change the gem amount of players |
| `k&k.experience` | Allows to change the exp amount of players |
| `k&k.donator` | Allows to change the donator rank of players |
| `k&k.kills` | Allows to change the kill amount of a player |
| `k&k.house` | Allows to create and edit houses |
| `k&k.home` | Allows to use the /home command |
| `k&k.room` | *(no description in source)* |
