# Docs session templates

Templates for the [knk-docs-session skill](SKILL.md). Fill in the `<…>` parts; leave out lines that don't apply.

## 1. Docs PR body

Fill in knk-workspace's `.github/pull_request_template.md`; for a docs PR its sections read like this.

```markdown
Closes PandiO/knk-workspace#<docs issue>

## Summary

Docs for PandiO/knk-workspace#<feature issue>, written against <repo> `<branch>` `<commit>`, ... (PRs: <links>).

1. <file>: <what changed>
2. ...

Differs from the plan: <behaviour, documented as the code does it; PandiO/knk-workspace#<issue> filed>, or none.

## Testing

1. Automated: docs only; the relative links added were checked.
2. Live / smoke test: <smoke-test guide steps amended, or n/a>.

## Docs impact

This PR is the docs follow-up; each line names the file changed or "n/a". Left over: <issues, or none>.

## Admin steps for deploy (essential, before merge)

None.

## Changelog

None (the feature's entry shipped with it). <Or: the correction made to its entry.>

---
_Generated by [Claude Code](https://claude.ai/code)_
```

## 2. Closing comment on the docs issue

```markdown
Docs done, merged into `<next|main>`.

1. PR: <link>, merge commit `<sha>` (<Codex: findings handled | skipped, usage limit>).
2. Files: <file> (<§ or one line>), ...
3. Differs from the plan: <behaviour → issue>, or none.
4. Issues filed: <links>, or none.
5. Left over: <links>, or nothing.
6. Decisions: <topic: chosen, alternatives (a), (b)>, or none.

---
_Generated by [Claude Code](https://claude.ai/code)_
```
